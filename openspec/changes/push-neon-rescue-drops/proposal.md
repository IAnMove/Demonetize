# Proposal: push-neon-rescue-drops

## Why
The run benefits from more short-term tension that is not just about survival score. Temporary rescue drops add a side objective without turning the game into escort defense.

## What Changes
- Add temporary rescue drops from defeated enemies from time to time.
- Let the player secure them by collecting them before they expire.
- Track rescued and lost totals for the run and show them in the final summary.

## Success Criteria
- Rescue drops create quick priority moments without slowing the run down.
- The end panel clearly shows how many targets were rescued and lost.
