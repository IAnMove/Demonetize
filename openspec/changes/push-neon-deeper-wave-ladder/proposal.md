# Proposal: push-neon-deeper-wave-ladder

## Why
Player feedback says the game can feel like it only has a few levels. The run already has chapter language, but the actual wave ladder should push deeper before the final clear.

## What Changes
- Extend the MVP run from 11 to 13 waves.
- Keep the existing wave 11 boss as a late-run breach instead of the final endpoint.
- Add two harder late waves with dense mixed threats and a final Overseer directive.
- Add one later standard upgrade window so the longer run has an extra build decision.

## Success Criteria
- The run feels deeper without adding new enemy systems.
- Late game pressure rises through existing archetypes and elite mutations.
- The MVP remains simple and static-host friendly.
