# Design: push-neon-build-fantasies

## Draft Model
- Keep the existing small curated pool.
- Bias standard offers toward the current primary and secondary build lanes.
- Preserve one flex or sustain slot often enough to avoid dead drafts.

## Build Language
Builds stay centered on:
- dash-killer
- glass-cannon
- spread-control

## UX
- Upgrade cards expose whether they are an anchor, surge, flex, or pivot for the current draft.
- The current build line should communicate commitment more clearly.

## Scope
This pass changes progression and presentation only. It does not add a new combat subsystem.
