# Proposal: push-neon-build-fantasies

## Why
The game already has upgrades and legendaries, but many runs still feel like a loose stack of stats. We need stronger build commitment and clearer draft decisions.

## What Changes
- Add a deeper build-draft pass with stronger lane bias and clearer pivots.
- Add a few more upgrades to reinforce dash, glass, and spread fantasies.
- Show upgrade fit more clearly in the between-wave UI.

## Success Criteria
- Runs should lock into a fantasy earlier.
- Upgrade picks should feel more intentional and less random.
- The player should read whether a choice reinforces or pivots the current build.
