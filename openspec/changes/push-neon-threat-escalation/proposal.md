# Proposal: push-neon-threat-escalation

## Why
The current MVP is readable and playable, but its pressure profile is still too contact-driven.
To improve jam impact, the game needs a more varied threat mix, a more memorable final encounter, stronger build fantasies, and a more compulsive retry loop.

## What Changes
- Add a ranged enemy archetype that forces repositioning
- Evolve the Overseer into a two-phase boss encounter
- Rebalance wave pacing around mixed threat composition
- Push builds toward clearer fantasy archetypes with stronger synergies
- Improve run-end presentation and jam-facing audiovisual feedback

## Success Criteria
- The player must react to more than melee chase pressure
- The final boss must feel structurally different from normal waves
- Runs should produce more distinct build identities
- The end screen should create a stronger "one more run" impulse
- The game should feel more presentable in the first 20 seconds of footage
