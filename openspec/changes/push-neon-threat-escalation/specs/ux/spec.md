# Delta for UX

## ADDED Requirements

### Requirement: Stronger run-end summary
The system SHALL explain run outcome, build identity, and record chase state at the end of a run.

#### Scenario: Run summary shown
- GIVEN a run ends
- WHEN the end panel appears
- THEN the player sees outcome flavor, build identity, and progress against records

### Requirement: Jam-facing presentation
The system SHALL support a stronger jam presentation layer for title and promo surfaces.

#### Scenario: First impression
- GIVEN a player or judge opens the game or sees promo art
- WHEN they evaluate the presentation
- THEN the game communicates its fantasy and retry loop quickly
