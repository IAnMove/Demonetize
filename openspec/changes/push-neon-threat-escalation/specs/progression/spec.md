# Delta for Progression

## ADDED Requirements

### Requirement: Clear build fantasies
The system SHALL reinforce recognizably different build directions during a run.

#### Scenario: Build identity emerges
- GIVEN the player has selected multiple upgrades
- WHEN the run progresses
- THEN the current build direction is reflected in gameplay and presentation

### Requirement: Legendary differentiation
The system SHALL make legendary rewards feel meaningfully different from standard upgrades.

#### Scenario: Legendary reward acquired
- GIVEN the player selects a legendary reward
- WHEN it is applied
- THEN the player gains a distinct mechanical and visual change
