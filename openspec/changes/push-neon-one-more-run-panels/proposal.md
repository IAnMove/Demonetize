# Proposal: push-neon-one-more-run-panels

## Why
The game already tracks strong run data, but the title and end screens still do not push the next attempt as hard as they could.
A clearer chase panel should tell the player exactly what to beat next and why another run matters immediately.

## What Changes
- Add a stronger next-target panel to the title screen
- Expand victory and defeat summaries with faster-to-read delta cards
- Highlight the single best next objective based on current records

## Success Criteria
- A player can glance at the title or final panel and understand one concrete goal for the next run
- Score, depth, and chain progress are easier to parse in a few seconds
- The retry CTA feels stronger without adding menu friction
