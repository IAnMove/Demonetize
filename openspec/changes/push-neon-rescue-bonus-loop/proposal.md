# Proposal: push-neon-rescue-bonus-loop

## Why
Timed rescue drops are readable now, but they still behave mostly like optional flavor. The run benefits more if saving them gives immediate payoff and the end panel frames extraction quality clearly.

## What Changes
- Grant an immediate reward when a rescue signal is secured.
- Track extraction efficiency for the run.
- Surface rescue performance more clearly in the final panels.

## Success Criteria
- Saving a rescue feels worth the risk during active combat.
- The end screen makes rescue performance legible at a glance.
