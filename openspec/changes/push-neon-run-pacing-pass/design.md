# Design: push-neon-run-pacing-pass

## Arena Boundary
- Clamp player movement and knockback against the visible arena rim instead of the wider hard-limit.

## Upgrade Cadence
- Standard upgrades trigger on milestone waves rather than after every wave.
- Chapter transition still grants elite choices.

## Run Length
- Increase the total wave count and add two more late-wave encounter themes.
- Keep chapter structure intact and push the final boss later.

## Variety
- Add a few more standard upgrades that strengthen existing build fantasies instead of creating a fourth build lane.
