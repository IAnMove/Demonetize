# Proposal: push-neon-run-pacing-pass

## Why
Recent content additions increased pressure and spectacle, but also made the run less readable. The arena border no longer feels solid, upgrades arrive too often for the current pacing, and the run still ends too soon for the size of the roster.

## What Changes
- Restore a hard-feeling collision at the visible arena rim.
- Space standard upgrades into clearer milestone waves.
- Expand the standard upgrade pool with more distinct choices.
- Extend the run with additional late waves.

## Success Criteria
- The player should feel blocked by the arena ring instead of sliding past it.
- Upgrade choices should feel more earned and less repetitive.
- A run should have more than the current early-wave cadence before the final boss.
