# Proposal: push-neon-upgrade-pacing-variety

## Why
Player feedback says upgrades arrive too early and can feel repetitive. The run should give the base kit a little more time to breathe, then make upgrade picks feel more varied.

## What Changes
- Move standard upgrade windows from waves 2/4/7/9 to waves 3/6/8/10.
- Add three standard upgrades with clear build fantasies and tradeoffs.
- Keep the chapter legendary pick unchanged.

## Success Criteria
- The first upgrade no longer interrupts the first minute too aggressively.
- The standard upgrade pool has more distinct picks.
- The final run still supports multiple build paths without adding new mechanics.
