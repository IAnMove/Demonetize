# Delta for Enemies

## ADDED Requirements

### Requirement: Chapter two elite threats
The system SHALL introduce elite escort enemies during later waves.

#### Scenario: Elite escort spawn
- GIVEN the run has entered chapter two
- WHEN a wave with elite budget begins
- THEN some escort enemies spawn with an elite mutation

### Requirement: Distinct elite mutations
The system SHALL provide readable elite mutation variants.

#### Scenario: Bulwark elite
- GIVEN a bulwark elite is active
- WHEN the player encounters it
- THEN it reads as a tougher slower threat than a normal escort
