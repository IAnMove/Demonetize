# Proposal: push-neon-signal-choir

## Why
The rescue system already influences tempo and drafting, but it still lacks a build-defining reward that belongs specifically to that fantasy.

## What Changes
- Add a rescue-themed elite upgrade called Signal Choir.
- Guarantee it appears in elite rescue-cache drafts when available.
- Give it effects that improve rescue reach, sustain, and tempo.

## Success Criteria
- Strong rescue play can open a clearly distinct legendary route.
- The upgrade feels thematically linked to extraction instead of generic power.
