# Proposal: push-neon-encounter-pacing

## Why
The roster is now richer, but waves still read too much like a flat stream. We need each encounter to have a cleaner opening, a pressure spike, and a readable finish.

## What Changes
- Add authored wave bursts instead of purely flat compositions.
- Use burst spacing to create ramps, spikes, and short breathers.
- Push chapter 2 toward stronger mixed-pressure encounters with artillery, elites, and purge threats.

## Success Criteria
- Waves should feel more intentional and memorable.
- Threat escalation should be easier to read.
- Mid and late runs should alternate pressure instead of staying flat.
