# Proposal: push-neon-relay-support

## Why
The roster now pressures movement well, but target priority is still too obvious in many fights. We need one enemy that makes the player decide what to kill first.

## What Changes
- Add a `relay` support enemy archetype.
- Let relay pulses reinforce nearby enemies for a short window.
- Add visual and audio feedback for active support pulses.
- Integrate relay units into chapter 2 wave mixes.

## Success Criteria
- Players should notice when the fight is being reinforced.
- Relay enemies should create meaningful target-priority decisions.
- Late waves should feel more layered without adding a heavy new subsystem.
