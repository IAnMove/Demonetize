# Proposal: push-neon-rescue-standard-draft

## Why
Rescue play already influences chapter drafting. Extending that logic to some standard upgrade windows makes the rescue layer matter more consistently across the run.

## What Changes
- Convert rescue progress into standard draft bonus charges.
- Spend a charge to open one extra standard upgrade option in a between-wave draft.
- Explain the rescue cache bonus in the between-wave UI when active.

## Success Criteria
- Rescue performance improves draft flexibility before chapter transition, not only at it.
- The extra choice is clearly explained and does not need new controls.
