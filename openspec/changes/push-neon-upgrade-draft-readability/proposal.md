# Proposal: push-neon-upgrade-draft-readability

## Why
Upgrade choices are mechanically meaningful, but the draft screen still reads too much like a vertical text list. The MVP needs faster build comprehension and stronger selection dopamine without adding new systems.

## What Changes
- Present upgrade choices laterally on desktop and stack them only on narrow screens.
- Give each upgrade card a stronger visual identity based on its build archetype.
- Add a compact option label so mouse selection feels like a deliberate draft pick.

## Success Criteria
- The player can compare all choices at a glance.
- Dash Killer, Glass Cannon, Spread Control, support, and legendary picks are visually distinct.
- The change remains DOM-only and does not affect combat simulation.
