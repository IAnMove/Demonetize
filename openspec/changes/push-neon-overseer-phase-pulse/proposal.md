# Proposal: push-neon-overseer-phase-pulse

## Why
The final Overseer fight has more pressure than before, but it still lacks a signature arena moment.
We need a boss-exclusive arena pattern that reads instantly and makes the final wave feel authored.

## What Changes
- Add a final-wave Overseer phase pulse attack
- Add warning and active phases for an expanding arena shock ring
- Add dedicated HUD, audio, and render cues for the pulse

## Success Criteria
- The final Overseer uses a memorable arena-wide pattern in phase 2
- Players can read the pulse before it damages them
- The pattern feels distinct from lane purges and dash rushes
